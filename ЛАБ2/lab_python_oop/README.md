## Установка и запуск

Из корня проекта на macOS/Linux:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r lab_python_oop/requirements.txt
python main.py
python -m unittest lab_python_oop.test_shapes -v
```

В Windows для создания окружения используйте `py -3 -m venv .venv`,
для активации в PowerShell — `.venv\Scripts\Activate.ps1`.
Остальные команды после активации совпадают.

## Структура

В корне находится точка входа `main.py`. Исходные модули, тесты,
файл зависимостей и эта инструкция находятся в пакете `lab_python_oop`.
`.venv` — локальное окружение, его следует создавать заново после
переноса проекта на другой компьютер.

- `shape.py` — абстрактный класс Shape, метод площади, метод класса.
- `color.py` — Color со свойством value и проверкой цвета.
- `rectangle.py` — Rectangle, наследование от Shape, композиция с Color.
- `circle.py` — Circle, площадь с использованием math.pi.
- `square.py` — Square, наследование от Rectangle.
- `test_shapes.py` — 10 тестов unittest, включая вариант 23.

В main.py вызывается внешний пакет colorama, установленный через pip.
Функция init(autoreset=True) настраивает цветной вывод. Прямоугольник
печатается синим, круг зеленым, квадрат красным. При перенаправлении
вывода ANSI-коды автоматически удаляются.

## Ожидаемый вывод

```text
Вариант: 23
Прямоугольник: ширина=23, высота=23, цвет=синий, площадь=529.00
Круг: радиус=23, цвет=зеленый, площадь=1661.90
Квадрат: сторона=23, цвет=красный, площадь=529.00
Внешний пакет: colorama; вызван init(autoreset=True).
```

Вычисления выполняются без округления; две цифры после точки
используются только в строковом представлении фигур.
